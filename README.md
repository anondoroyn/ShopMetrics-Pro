# ShopMetrics Pro

একটি Python ও Streamlit-ভিত্তিক ডেটা অ্যানালিটিক্স ড্যাশবোর্ড। বিভিন্ন কলামসহ Excel বা CSV ডেটা আপলোড করে স্বয়ংক্রিয় সারাংশ, ফিল্টার, ইন্টারেক্টিভ চার্ট এবং সাজানো টেবিল দেখুন।

## প্রজেক্টের পরিচিতি

ShopMetrics Pro আপলোড করা টেবুলার ডেটা পড়ে এবং সংখ্যাসূচক, তারিখ ও ক্যাটাগরি কলাম স্বয়ংক্রিয়ভাবে শনাক্ত করার চেষ্টা করে। ড্যাশবোর্ড দেখতে সাইডবার থেকে একটি CSV বা Excel ফাইল আপলোড করতে হয়; আপলোড না করা পর্যন্ত অ্যাপটি কোনো ডেমো ডেটা ব্যবহার না করে নির্দেশনামূলক নোটিশ দেখায়। Excel workbook হলে পছন্দের sheet বেছে নেওয়া যায়।

## মূল ফিচার

- **বিভিন্ন ধরনের টেবুলার ডেটা:** `.csv`, `.xlsx` এবং `.xls` ফাইল গ্রহণ করে; নির্দিষ্ট `Product`, `Sales` বা অন্য নামের কলাম বাধ্যতামূলক নয়।
- **Excel sheet নির্বাচন:** workbook-এর উপলব্ধ sheet থেকে একটি নির্বাচন করে বিশ্লেষণ।
- **আপলোড-নির্ভর ড্যাশবোর্ড:** কোনো ডেমো ডেটা নেই; ফাইল আপলোড না করলে নির্দেশনামূলক খালি অবস্থা দেখায়।
- **স্বয়ংক্রিয় ডেটা সারাংশ:** সারি, কলাম, সংখ্যাসূচক কলাম ও ফাঁকা ঘরের সংখ্যা।
- **কলামভিত্তিক পরিসংখ্যান:** নির্বাচিত সংখ্যাসূচক কলামের যোগফল, গড়, সর্বোচ্চ ও সর্বনিম্ন মান এবং পূর্ণ `describe()` সারাংশ।
- **স্বয়ংক্রিয় ফিল্টার:** কম সংখ্যক স্বতন্ত্র মানের ক্যাটাগরি/গ্রুপ কলাম এবং শনাক্ত করা তারিখ কলামের জন্য ফিল্টার।
- **ইন্টারেক্টিভ Plotly চার্ট:** উপলভ্য কলাম অনুযায়ী Bar, Line বা Pie chart; সংখ্যাসূচক কলাম না থাকলে category count chart।
- **লাইট ও ডার্ক মোড:** সাইডবার থেকে থিম বেছে নিন; চার্টের রং ও ব্যাকগ্রাউন্ডও সেই অনুযায়ী বদলায়।
- **পরিষ্কার অ্যাপ ইন্টারফেস:** Streamlit-এর built-in toolbar লুকানো থাকে।
- **সাজানো ডেটা টেবিল:** ফিল্টার করা সারিগুলো ইন্টারেক্টিভ টেবিলে দেখুন।
- **CSV ডাউনলোড:** ফিল্টার করা ডেটা CSV হিসেবে সংরক্ষণ করুন।
- **Gemini AI ইনসাইট:** সম্মতি দিলে ফিল্টার করা ডেটার সারসংক্ষেপ পরিসংখ্যান থেকে বাংলায় AI ইনসাইট তৈরি করে; মূল সারি ও ক্যাটাগরির মান পাঠায় না।
- **ইনপুট যাচাই:** ফাইল খালি বা পড়ার অনুপযোগী হলে স্পষ্ট বার্তা দেখায়।

## ইনস্টলেশন ও চালানোর নিয়ম

Python ইনস্টল থাকা নিশ্চিত করে প্রজেক্ট ফোল্ডারে টার্মিনাল খুলুন।

1. ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও চালু করুন:

   **Windows PowerShell**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **macOS / Linux**

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Excel ফাইল আপলোড করতে সংশ্লিষ্ট রিডার ইনস্টল করুন:

   ```bash
   python -m pip install openpyxl
   ```

   পুরোনো `.xls` ফাইলের জন্য:

   ```bash
   python -m pip install xlrd
   ```

4. ড্যাশবোর্ড চালু করুন:

   ```bash
   python -m streamlit run Metrics_Pro.py
   ```

   Streamlit যে লোকাল URL দেখাবে সেটি ব্রাউজারে খুলুন—সাধারণত `http://localhost:8501`।

## Gemini API কনফিগারেশন

Gemini ইনসাইট ব্যবহার করতে Google AI Studio থেকে একটি Gemini API key নিন, তারপর নিচের যেকোনো একটি উপায়ে সেট করুন।

**প্রজেক্টের Streamlit secrets ফাইলে** `.streamlit/secrets.toml` তৈরি করে লিখুন:

```toml
GEMINI_API_KEY = "আপনার-API-key"
```

অথবা, Windows PowerShell-এ বর্তমান টার্মিনাল সেশনের জন্য environment variable সেট করুন:

```powershell
$env:GEMINI_API_KEY = "আপনার-API-key"
```

ডিফল্ট মডেল `gemini-3.8-flash`; প্রয়োজনে `GEMINI_MODEL` environment variable দিয়ে মডেল বদলানো যায়। API key কখনো source code-এ লিখবেন না বা Git-এ commit করবেন না। `.streamlit/secrets.toml` ইতোমধ্যে `.gitignore`-এ বাদ দেওয়া আছে।

ইনসাইট তৈরির আগে অ্যাপে সম্মতি দিতে হবে। Google Gemini API-তে শুধু কলামের নাম, ডেটার ধরন, ফাঁকা মানের সংখ্যা, সংখ্যাসূচক সারাংশ, তারিখের পরিসর এবং স্বতন্ত্র মানের সংখ্যা পাঠানো হয়—মূল ডেটার সারি বা ক্যাটাগরির মান নয়। Gemini API ব্যবহারে Google-এর মূল্য ও ব্যবহারের শর্ত প্রযোজ্য।

## আপলোড ফাইলের ফরম্যাট

Excel ও CSV-তে প্রথম সারি কলামের শিরোনাম হিসেবে ব্যবহার করা হয়। কোনো নির্দিষ্ট কলাম-নাম বাধ্যতামূলক নয়। ভালো সারাংশ ও চার্টের জন্য সংখ্যাসূচক কলাম (যেমন `Sales`, `Revenue`, `Quantity`), তারিখ কলাম এবং বর্ণনামূলক গ্রুপ কলাম (যেমন `Category`, `Product`, `Department`) রাখা সহায়ক।

| কলামের ধরন | উদাহরণ | ড্যাশবোর্ডে ব্যবহার |
|---|---|---|
| সংখ্যাসূচক | `Sales`, `Amount`, `Quantity` | পরিসংখ্যান ও চার্টের মান |
| তারিখ/সময় | `Order Date`, `Timestamp` | ঐচ্ছিক তারিখ ফিল্টার ও সময়ভিত্তিক চার্ট |
| ক্যাটাগরি/লেবেল | `Product`, `Category`, `Department` | ঐচ্ছিক গ্রুপ ফিল্টার ও চার্ট |

Excel workbook-এ পছন্দের sheet নির্বাচন করুন। প্রথম সারিতে পরিষ্কার, আলাদা কলাম-শিরোনাম রাখুন এবং পরিসংখ্যানের জন্য প্রাসঙ্গিক কলামে সংখ্যাসূচক মান দিন। ডেটা পরিষ্কারভাবে ব্যাখ্যা করতে প্রথম সারির আগের অতিরিক্ত শিরোনাম/নোট সরিয়ে দিন।

## বিশ্লেষণ ও সীমাবদ্ধতা

- মেট্রিক ও চার্ট নির্বাচিত ফিল্টারের পর থাকা ডেটা থেকে তৈরি হয়।
- তারিখ কলাম স্বয়ংক্রিয় শনাক্তকরণ মূলত তারিখ-সম্পর্কিত শিরোনাম এবং Excel-এর date cell-এর ওপর নির্ভরশীল।
- প্রথম সারি কলাম-শিরোনাম এবং প্রথম sheet ডিফল্ট হিসেবে ব্যবহৃত হয়; Excel-এর জন্য অন্য sheet ম্যানুয়ালি নির্বাচন করা যায়।
